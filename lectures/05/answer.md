- 検索だけを実行して見つかったページと、その本文で確認できたこと：
  - 上位5件は p.52、p.51、p.60、p.61、p.47 。
  - p.52 の本文に、質問の答えがそろっています。
    - LoRA は元の重み W を固定し、小さな行列 A・B だけを学習する。
    - QLoRA は元の重みを 4bit に圧縮する（約 1/4、7B なら約 4GB）。

- 今回の用途に採用したい方式と、その理由・比較条件の限界：
  - 採用案：ベクトル検索。理由は次のとおり。
    - 費用が最小（0.001223 USD）。
    - 入力が 3,031 トークンと少ない。
    - 4.92 秒と速い。
    - 回答が正しく、p.51・p.52 というページ単位の根拠が示せる。
  - 次点：Graph。前後ページや関連語まで補足したい質問では候補になる。
  - 限界：
    - 質問が 1 問、実行が 1 回だけで、単一ページで答えが完結する質問だった。複数ページや複数回にまたがる質問では順位が変わる可能性がある。
    - 費用は生成 API のみで、埋め込み・索引構築・Tree や Graph の事前作成コストは含まない。
    - 全文投入だけ対象講義の絞り込みがなく、母集団が他方式と同じか未確認。
    - 正しさの判定は、検索結果の本文との目視照合による。
